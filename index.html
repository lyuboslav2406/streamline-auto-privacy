Privacy Policy

StreamLine Auto Publisher

Effective date: August 17, 2026

This Privacy Policy describes how StreamLine Auto Publisher ("the Application") accesses and uses information when interacting with Facebook Pages through Meta's APIs.

StreamLine Auto Publisher is an internal business publishing tool used by authorized personnel to prepare, publish, and schedule vehicle-related content on Facebook Pages managed by StreamLine Auto.

1. Purpose of the Application

The Application is used to streamline the preparation and publication of vehicle listings and related business content.

Authorized users may prepare post text, select and organize vehicle images, publish posts immediately, or schedule posts for later publication.

2. Meta and Facebook Data Access

The Application uses the Meta Graph API and Facebook Pages API. It requests only permissions required to operate its Page publishing functionality.

Depending on the configuration approved by Meta, these permissions may include:

  • pages_manage_posts — used to create and manage posts on authorized Facebook Pages.
  • pages_read_engagement — used to access Page information necessary for Page-related API operations.
  • pages_show_list — used to identify Facebook Pages that an authorized account or system user has permission to manage.

The Application does not request access to Facebook Pages that have not been explicitly authorized for use with the Application.

3. Information We Process

The Application may process limited information provided by Meta that is necessary to identify and manage an authorized Facebook Page, including:

  • Facebook Page ID;
  • Facebook Page name;
  • Page access permissions and publishing capabilities;
  • identifiers of posts or media created through the Application;
  • API responses required to confirm publication or scheduling.

The Application is not designed to collect personal Facebook profile information from members of the public.

4. How Information Is Used

Information accessed through Meta's APIs is used only for legitimate operation of the StreamLine Auto publishing workflow.

In particular, it may be used to:

  • identify an authorized Facebook Page;
  • upload vehicle images;
  • publish Page posts;
  • schedule Page posts;
  • confirm whether a publishing request succeeded;
  • retrieve identifiers or permalinks for content created by the Application.

5. User Control and Publishing

StreamLine Auto Publisher is operated by authorized business users. The Application does not independently select third-party Facebook Pages or publish content to unauthorized Pages.

Content publication is initiated or scheduled through the Application by an authorized operator.

6. Data Sharing and Sale

We do not sell Facebook or Meta platform data.

We do not rent Facebook or Meta platform data to third parties and do not use such data for unrelated advertising, profiling, or data brokerage purposes.

Information may be transmitted to service providers strictly when necessary for operating the Application, such as hosting infrastructure used to run the publishing service.

7. Data Storage and Retention

The Application is designed to retain only information necessary to operate its publishing functionality.

Facebook Page access credentials are stored securely as server-side configuration and are not exposed to public users through the Application interface.

Temporary generated vehicle images and post-processing information may be stored for the period necessary to complete the publishing workflow.

We do not intentionally create a permanent database of Facebook user profile information.

8. Security

Reasonable technical and organizational measures are used to protect access credentials and the Application.

Facebook access tokens and other credentials are stored server-side and are not intended to be embedded in publicly accessible client-side code.
